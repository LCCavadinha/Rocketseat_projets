# 🌏 Desafio Local Turístico – Busan

Projeto desenvolvido como parte dos desafios práticos do curso da Rocketseat, com foco em estruturação semântica de HTML e organização de layout utilizando CSS.

## 📌 Objetivo

Construir uma página estática apresentando um destino turístico, aplicando:

- Estrutura semântica com HTML5
- Organização de layout com CSS
- Uso adequado de tipografia externa (Google Fonts)
- Hierarquia visual clara
- Estruturação de componentes reutilizáveis

---

## 🖼 Demonstração

Projeto estático exibindo:

- Seção de introdução
- Bloco descritivo com imagem central
- Lista de destinos com cards informativos
- Rodapé estilizado

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Google Fonts (Open Sans)
- Font Awesome

---

## 🧠 Decisões Técnicas

- Uso de estrutura semântica com `<main>`, `<section>`, `<footer>`
- Separação clara entre conteúdo e estilo
- Centralização do layout com container fixo (`1120px`)
- Aplicação de hierarquia visual por tipografia
- Uso de classes utilitárias para cores específicas das categorias
- Reset global utilizando `* { box-sizing: border-box }`

---

## 🎯 Pontos de Aprendizado

- Organização de conteúdo em seções semânticas
- Estruturação de cards reutilizáveis
- Controle de espaçamento e ritmo visual
- Padronização de tipografia
- Manipulação de listas estilizadas
