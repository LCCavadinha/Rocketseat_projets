# 🛼 Snitap – Landing Page Animada

Landing page responsiva com foco em motion design e animações avançadas utilizando apenas HTML e CSS.

Projeto desenvolvido como prática de:

- Animações com keyframes
- Scroll-based animation
- Interações com hover
- Layout responsivo mobile-first
- Organização modular de estilos

---

## 🎯 Objetivo

Construir uma landing page promocional para uma marca fictícia de patins com forte apelo visual e animações fluidas.

A proposta foi explorar:

- Microinterações
- Transições suaves
- Elementos animados no carregamento
- Scroll animations
- Efeitos visuais com gradientes

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Mobile-first
- CSS Grid
- Flexbox
- Keyframes animations
- Scroll animations (`animation-timeline`)
- Media queries modernas (`width >= 80em`)
- Modularização de CSS
- Google Fonts (Montserrat, Syne)
- Font Awesome

---

## 🧠 Conceitos Aplicados

### 1️⃣ Animações de Entrada

- `slideIn`
- `appear`
- Uso de `animation-delay`
- Controle de `forwards` e `both`

### 2️⃣ Animação de Texto Dinâmico

- Keyframes complexos para alternar palavras
- Controle preciso de `translateY`
- Ajuste de altura dinâmica entre mobile e desktop

### 3️⃣ Scroll-Based Animation

- Uso de `animation-timeline: view()`
- `animation-range`
- Aparição progressiva de imagens na galeria

### 4️⃣ Microinterações

- Botões com `transform: scale`
- Hover com transições suaves
- Ícones com rotação
- Underline animado via pseudo-elemento

### 5️⃣ Gradientes Animados

- `background-size: 400%`
- Animação contínua com `@keyframes`

---

## 📱 Responsividade

- Estrutura mobile-first
- Layout reorganizado no desktop com Grid
- Ajustes de proporção de imagens
- Redefinição de keyframes para desktop
