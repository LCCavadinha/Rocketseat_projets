# 🧁 Página de Receita – Cupcake de Café com Chantilly

---

## 📌 Objetivo

Construir uma página estática de receita aplicando:

- Estrutura semântica com HTML5
- Organização visual utilizando CSS
- Hierarquia tipográfica
- Controle de espaçamento e ritmo visual
- Aplicação de imagem de fundo e container centralizado

---

## 🖼 Demonstração

Página estática contendo:

- Imagem principal da receita
- Informações gerais (tempo, rendimento, dificuldade)
- Lista de ingredientes
- Modo de preparo detalhado
- Layout centralizado com background decorativo

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Google Fonts (Alice)
- Font Awesome

---

## 🧠 Decisões Técnicas

- Uso de `<main>` e `<section>` para organização semântica
- Separação clara entre conteúdo e estilo
- Container fixo centralizado (`width: 800px`)
- Uso de `background-image` no `body`
- Aplicação de bordas arredondadas para reforço visual
- Controle de espaçamento usando combinadores (`section + section`, `p + p`)

---

## 🎯 Pontos Trabalhados

- Estruturação de conteúdo longo
- Estilização de listas
- Aplicação de tipografia externa
- Controle de contraste de cores
- Organização visual baseada em blocos
