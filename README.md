# 💼 Portfólio Dev – Landing Page Pessoal

Projeto desenvolvido como desafio prático com foco na construção de uma landing page de portfólio pessoal, aplicando organização modular de CSS, estrutura semântica e composição visual.

---

## 📌 Objetivo

Desenvolver uma página de apresentação profissional contendo:

- Seção de introdução com identidade visual
- Projetos em destaque
- Serviços oferecidos
- Seção de contato
- Estrutura escalável e organizada

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Variáveis CSS (Custom Properties)
- Modularização de estilos
- Google Fonts (Asap, Inconsolata, Maven Pro)
- Font Awesome

---

## 🧠 Arquitetura de Estilos

O CSS foi organizado em camadas para manter separação de responsabilidades:

### global.css

- Reset
- Tokens de design (cores e tipografia)
- Configuração base de títulos e textos

### utility.css

- Classes utilitárias reutilizáveis (`grid`, `flex`, `gap-*`)
- Classes de cor
- Helpers de layout

### header.css

- Estrutura da seção de introdução
- Avatar com posicionamento relativo/absoluto
- Tags de tecnologias

### sections.css

- Layout das seções principais
- Grid de cards
- Estruturação da seção de serviços
- Layout da área de contato

---

## 🎯 Conceitos Trabalhados

- Organização modular de CSS
- Design tokens via custom properties
- Combinação de Grid + Flexbox
- Layout baseado em componentes
- Estrutura escalável para expansão futura
- Separação visual por seções bem definidas
